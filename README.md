# 🧭 数学大冒险 · 小学数学练习 Web App

人教版小学数学 1-6 年级趣味练习应用，为家里的两位小朋友（妹妹一年级 / 哥哥六年级）打造。
手机 / 平板优先设计，数据保存在浏览器本地（localStorage），无需服务器与登录。

## ✨ 核心特性

- **每局 10 题**：🌱简单+🍀中等 5 题 · 🔥困难 4 题 · 🚀拓展 1 题
- **题目随机生成**：56 个主题生成器（一至六年级人教版大纲），每题数字随机，练不完
- **三年级起保证应用题**（每局至少 2 道），题目配 SVG 插图：钟面、人民币、小棒、数轴、
  分数条/扇形、方格图、几何图形（带标注）、条形/扇形统计图、长方体/圆柱/圆锥、方程天平等
- **答错不放弃**：不跳题、不直接给答案。答错后猫头鹰老师 🦉 逐步给出 3-5 条提示
  （概念 → 条件梳理 → 思路 → 列式 → 首步结果），最后一步永远由孩子自己完成；
  提示全部用完仍可继续尝试，也可"先跳过"（同样不给答案，0 分）
- **积分激励**：难度分值 10/20/30/50；一次答对 3 星（100% 分），错 1 次 2 星（70%），
  多次后 1 星（40%）；拓展题 3 星额外 +20；连续 3 题一次答对 +10 🔥
- **等级 + 徽章 + 弱项专项**：7 个等级称号、9 枚徽章；结算页自动推荐薄弱主题一键专项练习
- **多档案**：每个孩子独立档案（头像 / 年级 / 积分 / 成就），支持新增与编辑

## 🚀 使用

```bash
npm install
npm run dev        # 手机/平板访问启动时打印的局域网地址，如 http://192.168.x.x:5173
```

其他命令：

```bash
npm test           # 单元测试（判题器、56 个生成器结构校验、组卷规则）
npm run build      # 类型检查 + 生产构建（产物在 dist/，可部署到任意静态托管）
npm run preview    # 本地预览生产构建
```

> 手机/平板提示：用 Safari「添加到主屏幕」即可像 App 一样全屏使用。

## 🗂 目录结构

```
src/
  types.ts            题目/答案/图形类型定义
  lib/
    rng.ts            可复现随机数
    math.ts           gcd/约分等工具
    checker.ts        判题器（数值/分数/比/比大小/选择）
    session.ts        组卷引擎（5+4+1 配比、应用题保证、防重复）
    scoring.ts        星级、积分、等级
    sound.ts          WebAudio 音效
  figures.tsx         24 种 SVG 题目图形组件
  generators/         一至六年级题目生成器（g1~g6 + 注册表）
    helpers.ts        出题脚手架：渐进提示模板、乘法口诀等
  pages/              首页 / 选年级专项 / 答题 / 结算 / 成就
  components/         答题键盘（数字/分数/比/比大小/选择）、提示面板等
  store.ts            zustand + localStorage 持久化档案
```
